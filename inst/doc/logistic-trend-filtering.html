A binary response gives a zero or one at each observation, but the quantity we want to estimate is a probability curve. Here we fit

\[ Y_i\mid x_i\sim\operatorname{Bernoulli}(p(x_i)),\qquad \operatorname{logit}p(x)=f(x). \]

Order 2 means piecewise quadratic on the logit scale. The absolute-value penalty on third divided differences lets different parts of the curve have different amounts of curvature. A large penalty removes adaptive knots and approaches a quadratic logit curve. It does not force a linear logit curve. Conversely, ordinary linear logistic regression already gives a curved, S-shaped probability response; that shape alone is not evidence of a nonlinear logit relationship.

This vignette first uses known synthetic probabilities, then the published Pima training/test data in MASS. We compare a constant probability, a linear logit, a quadratic logit, a natural-spline logit and trend filtering. All tuning uses training outcomes only. Separate test outcomes assess probability prediction; training fit is not used as evidence of predictive improvement.

A complete fit and a clear validation boundary

Supply a penalty path explicitly. lambda refers to predictor locations normalized to the training range, so it is not expressed in the original units of x. The default lambda.selection="fixed" returns a path without selecting one member. To select by minimum cross-validated log loss, supply training-fold labels:

make_folds <- function(y, k=5L, seed=1L) {
    set.seed(seed)
    fold <- integer(length(y))
    for (value in c(0, 1)) {
        at <- which(y == value)
        fold[at] <- sample(rep(seq_len(k), length.out=length(at)))
    }
    fold
}
log_loss <- function(y, eta) {
    mean((1-y)*pmax(eta, 0) + y*pmax(-eta, 0) +
         log1p(exp(-abs(eta))))
}
probability_scores <- function(y, eta, truth=NULL) {
    p <- plogis(eta)
    c(`Log loss`=log_loss(y, eta), `Brier score`=mean((p-y)^2),
      `Probability RMSE`=if (is.null(truth)) NA_real_ else sqrt(mean((p-truth)^2)))
}
lambda_path <- c(Inf, 10^seq(0, -4, by=-0.5))
spline_df <- c(3L, 5L, 7L)

By default, cv.penalty.scale="training_mass" multiplies each fold’s lambda and explicit ridge coefficients by its training/full weight-sum ratio. The fitting loss is a sum, so this preserves the penalty coefficient relative to mean loss. For example, four-fifths of the observations with unit weights use four-fifths of the reference penalty. The selected full-data fit uses the original supplied penalty. cv.penalty.scale="none" reproduces the earlier unchanged-numerical-penalty convention. Training ranges and covariate transformations are still recomputed within folds. Inspect cv.fold.lambda, cv.fold.penalty.factors, and cv.fold.ridge to see the actual fold settings.

The examples have independent observations, so the five folds are stratified by training outcome and assigned at the observation level. Repeated specimens from one person should instead share a fold label. Splitting must reflect the unit that will be held out in the intended application.

Log loss uses natural logarithms and evaluates the predicted probability of the observed outcome. The Brier score is squared probability error against the binary response. Both are lower-is-better prediction losses. Synthetic examples also allow probability RMSE against the known generating curve; this measure is unavailable for the real data.

Reusable fitting and plotting helpers are printed in the appendix. They learn predictor normalization, spline knots and covariate scaling within each training fold. The natural spline selects 3, 5 or 7 degrees of freedom using the same folds and loss as trend filtering. Constant, linear and quadratic logit models have no tuning parameter. All models use zero additional ridge in the comparisons below.

Recover known probability curves

Both examples use 600 training observations and 2,000 independently drawn test observations. Locations are uniform on [0,1]. The formulas below specify the true log odds before any observations are generated or models compared:

Example True log odds Purpose
Linear logit -2 + 4*x Ordinary linear logistic regression is correctly specified.
Local changes -1.4 + 2.8*exp(-((x-.35)/.08)^2) - 1.5*exp(-((x-.75)/.15)^2) A narrow peak and broader trough require locally varying curvature. 
truth_eta <- list(
    `Linear logit`=function(x) -2+4*x,
    `Local changes`=function(x) -1.4+2.8*exp(-((x-.35)/.08)^2)-
        1.5*exp(-((x-.75)/.15)^2))
synthetic <- vector("list", length(truth_eta)); names(synthetic) <- names(truth_eta)
for (j in seq_along(truth_eta)) {
    set.seed(9100L+j)
    train_x <- runif(600); train_p <- plogis(truth_eta[[j]](train_x))
    train_y <- rbinom(600, 1, train_p)
    test_x <- runif(2000); test_p <- plogis(truth_eta[[j]](test_x))
    test_y <- rbinom(2000, 1, test_p)
    folds <- make_folds(train_y, seed=110L+j)
    fit <- fit_comparison(train_x, train_y, folds)
    synthetic[[j]] <- list(x=train_x, y=train_y, test_x=test_x,
        test_y=test_y, test_p=test_p, folds=folds, fit=fit)
}

The probability-RMSE column compares each prediction with the generating probability at the same test location. Log loss and Brier score also include binary sampling variation. These two fixed examples illustrate possible behaviors, including extra flexibility when the linear model is correct. They are not a repeated-simulation ranking or a claim that trend filtering always wins. Predictions outside the training range are included: trend filtering holds its boundary curve value, while the reference models extrapolate their specified functions.

Exact ties and binomial trial weights

Repeated values of x share a curve value. When no covariates or offsets differ within a group, independent binary trials can equivalently be represented by a success proportion and trial count. This is an equality of likelihoods, not a reason to bin distinct predictor values.

Pima data: fit on training women, assess on test women

MASS::Pima.tr and MASS::Pima.te contain a published random split of 532 complete records into 200 training and 332 test subjects. The population was women of Pima heritage, aged at least 21, living near Phoenix, Arizona; diabetes status was determined according to WHO criteria. These examples classify the recorded diabetes status, not future disease onset or a causal glucose effect. See the MASS dataset documentation for provenance and variable definitions. This complete-record subset does not represent all patients or resolve the original missing-data selection.

The classical minimax-rate result concerns appropriately tuned Gaussian trend filtering over specified function classes. It does not automatically establish optimality for this logistic model, covariate adjustment or a selected real-data curve. This vignette supports reproducible fitting and assessment, not a claim of universal superiority. No confidence band is supplied that would ignore penalty and knot selection.

Does the probability vary with the predictor?

The global question is whether all observed predictor locations share one unknown binary probability. The null estimate is the sample event rate. This differs from asking where the curve departs from a constant, and rejecting constancy does not by itself establish nonlinearity: linear logistic regression can also describe a nonconstant probability.

assess.logistic.trend.filtering() takes a fitted object and performs two separate assessments. It retunes the supplied, prespecified penalty path on new outcome-independent folds, then repeats this complete procedure after each outcome permutation. Its default statistic is twice the ordinary binomial log-likelihood improvement over the constant, truncated at zero for numerical roundoff. The returned fit is this newly tuned fit; the input object’s fold labels and selected penalty are not reused. This avoids conditioning on folds that may have been stratified using the observed outcomes.

Separately, nested CV estimates prediction loss: outer test outcomes enter neither penalty selection nor the outer-training event rate used as the constant baseline. Improvement means constant loss minus smoother loss. Positive values favor the smoother. These are predictive assessment scores, not confidence intervals or a second significance test.

The following fixed examples use independent binary observations without covariates, offsets or weights. One has constant probability 0.35; the other has a localized probability peak. The predictor, penalty path and all solver settings are specified before generating outcomes. There are 160 observations per example. We use 99 permutations to keep routine builds short, giving p-value resolution 0.01; the assessment function defaults to 999. These two examples illustrate the outputs, not average false-positive rates or power. How large is the fitted departure from constancy?

Every assessment returns curve.summaries, even when only the default likelihood test is requested. With fitted probabilities \(\hat p(x_i)\) and sample event rate \(\bar y\), absolute deviation is

\[ \delta_0 = \frac{1}{n}\sum_{i=1}^n |\hat p(x_i)-\bar y|. \]

This averages over participants, including multiple participants at the same predictor value. It does not give equal weight to sparsely and densely sampled parts of a uniformly spaced grid. For example, \(\delta_0=0.04\) means an average absolute probability difference of four percentage points. It summarizes the fitted curve; sampling noise and smoothing bias still affect it.

Total variation measures accumulated rises and falls across the entire observed predictor range. Let \(s_1,\ldots,s_K\) be the ordered endpoints, knots and interior turning points of the fitted curve. Then

\[ \delta_1 = \sum_{j=2}^K |\hat p(s_j)-\hat p(s_{j-1})|. \]

The logit is quadratic between knots, so its interior turning points can be located algebraically. The implementation evaluates each segment’s endpoints and midpoint to recover that quadratic in local coordinates. Since the logistic transformation is monotone, the probability curve has the same turning points. This avoids missing an interior peak on a coarse grid. A monotone curve’s total variation equals its absolute endpoint difference; several rises and falls can accumulate to a value above one. Total variation is sensitive to small oscillations and is distinct from the order-2 penalty.

Inspect assessment$permutations, assessment$permutation.diagnostics and assessment$prediction$diagnostics for numerical failures. If any permutation cannot select a valid fit, p.value is unavailable; p.value.bounds shows the range obtained by counting each missing statistic at either extreme. That range is not a confidence interval. Incomplete outer predictions similarly leave the smoother’s overall prediction scores unavailable. Failed fits are not dropped and denominators are not reduced to successful replicates. For optional tests, inspect tests and permutation.statistics. Missing statistics leave the affected individual p-value unavailable, with lower and upper failure bounds. If any requested test is incomplete, the whole Holm column is unavailable. A curve-summary arithmetic failure is recorded in curve.summary.details or the corresponding permutation diagnostic; it does not erase an otherwise available likelihood statistic. Neither the summaries nor their tests provide pointwise or simultaneous confidence bands.

Unrestricted outcome shuffling is not valid for repeated participants, dependent observations or confounder-adjusted null hypotheses. The assessment rejects nonbinary responses, nonunit weights, covariates and offsets; callers must establish independence. A path or predictor chosen after inspecting outcomes is an additional selection step that this assessment does not repeat. This workflow uses an outcome permutation under the null, rather than a bootstrap intended to estimate uncertainty around the fitted alternative.

What would a 95% uncertainty band mean?

The current fitter returns point estimates and convergence diagnostics, not standard errors or posterior draws. The Wilson intervals in the Pima figures describe observed bin proportions; they are not confidence bands for the trend-filtering curve.

A pointwise 95% interval concerns the probability at one prespecified predictor value. A simultaneous 95% band aims to cover the entire curve over a specified domain; taking pointwise intervals at many locations does not produce such a band. A region average, contrast between regions, or location of an adaptive knot is another inferential target and needs its own uncertainty calculation.

One practical extension is a bootstrap of the complete fitting procedure, including penalty selection in each replicate. Independent observations may be resampled individually; repeated observations should be resampled by participant, and each participant’s copies must remain together in tuning folds. Binomial trial weights and any covariates or offsets must retain their sampling meaning. Failed fits and their frequency must be reported rather than silently dropped. Penalization bias and unstable knot selection can make ordinary bootstrap intervals miscalibrated. Before describing them as 95% confidence intervals, assess pointwise and simultaneous coverage separately on simulations with known truth, including sparse predictor regions, strong curvature and near-separation. A fixed-lambda bootstrap answers a different question from one that repeats tuning.

Bayesian credible intervals require an explicit probability model and priors, for example a binomial likelihood with shrinkage on third divided differences and proper priors on the unpenalized quadratic component and any covariates. Posterior sampling, smoothing-scale uncertainty and sampler diagnostics are additional work; optimizing the current penalized objective does not supply posterior draws. Bayesian trend filtering provides a precedent for binomial models. Its credible intervals express posterior uncertainty under the chosen model, without automatically guaranteeing 95% frequentist coverage. Likewise, the Gaussian generalized-lasso selective-inference results do not directly supply confidence bands for this cross-validated logistic fit.

Reusable analysis helpers

These helpers implement the comparisons and figures above. In particular, fit_reference() is called anew inside each spline-training fold; its stored model terms retain that fold’s spline knots for prediction.

method_names <- c("Constant probability", "Linear logit", "Quadratic logit",
                  "Natural spline", "Trend filtering")
curve_colors <- c("Linear logit"="#0072B2", "Quadratic logit"="#009E73",
                  "Natural spline"="#8B5AA5", "Trend filtering"="#D55E00")

fit_reference <- function(x, y, kind, df=NULL, covariates=NULL) {
    lo <- min(x); span <- diff(range(x))
    if (!is.finite(span) || span <= 0) stop("Training predictor needs a positive range.")
    d <- data.frame(y=y, u=(x-lo)/span)
    zcenter <- zscale <- numeric()
    if (!is.null(covariates)) {
        zcenter <- colMeans(covariates)
        zz <- sweep(covariates, 2, zcenter)
        zscale <- sqrt(colMeans(zz^2))
        if (any(zscale <= 0)) stop("Constant training covariate.")
        zz <- sweep(zz, 2, zscale, "/")
        for (j in seq_len(ncol(zz))) d[[paste0("z", j)]] <- zz[, j]
    }
    rhs <- switch(kind, constant="1", linear="u", quadratic="u + I(u^2)",
                  spline=sprintf("splines::ns(u, df=%d)", df))
    if (length(zcenter)) rhs <- paste(rhs, paste0("z", seq_along(zcenter), collapse=" + "), sep=" + ")
    messages <- character()
    fit <- withCallingHandlers(
        stats::glm(stats::as.formula(paste("y ~", rhs)), data=d,
                   family=stats::binomial(), control=stats::glm.control(maxit=100)),
        warning=function(w) {
            messages <<- c(messages, conditionMessage(w))
            invokeRestart("muffleWarning")
        })
    if (!fit$converged || any(!is.finite(stats::coef(fit))) || length(messages))
        stop(paste(c("Reference fit did not pass convergence checks.", messages), collapse=" "))
    list(model=fit, lo=lo, span=span, zcenter=zcenter, zscale=zscale)
}
predict_reference <- function(object, x, covariates=NULL) {
    d <- data.frame(u=(x-object$lo)/object$span)
    if (length(object$zcenter)) {
        zz <- sweep(sweep(covariates, 2, object$zcenter), 2, object$zscale, "/")
        for (j in seq_len(ncol(zz))) d[[paste0("z", j)]] <- zz[, j]
    }
    eta <- as.numeric(stats::predict(object$model, newdata=d, type="link"))
    if (any(!is.finite(eta))) stop("Nonfinite reference prediction.")
    eta
}
fit_comparison <- function(x, y, folds, covariates=NULL) {
    basic <- lapply(c("constant", "linear", "quadratic"), function(kind)
        fit_reference(x, y, kind, covariates=covariates))
    names(basic) <- method_names[1:3]
    losses <- matrix(NA_real_, max(folds), length(spline_df))
    spline_status <- matrix("complete", max(folds), length(spline_df))
    for (k in sort(unique(folds))) for (j in seq_along(spline_df)) {
        train <- folds != k; test <- !train
        ztrain <- if (is.null(covariates)) NULL else covariates[train, , drop=FALSE]
        ztest <- if (is.null(covariates)) NULL else covariates[test, , drop=FALSE]
        result <- tryCatch({
            fit <- fit_reference(x[train], y[train], "spline", spline_df[j], ztrain)
            log_loss(y[test], predict_reference(fit, x[test], ztest))*sum(test)
        }, error=function(e) e)
        if (inherits(result, "error")) spline_status[k, j] <- conditionMessage(result)
        else losses[k, j] <- result
    }
    cv_loss <- colSums(losses)/length(y)
    if (!any(is.finite(cv_loss))) stop("No spline candidate passed all training folds.")
    selected_df <- spline_df[which.min(replace(cv_loss, !is.finite(cv_loss), Inf))]
    spline <- fit_reference(x, y, "spline", selected_df, covariates)
    # Candidate failures are displayed in the diagnostic tables below.
    tf <- fit.logistic.trend.filtering(x, y, lambda=lambda_path,
        covariates=covariates, lambda.selection="cv", foldid=folds,
        backend="banded", warn=FALSE)
    if (is.null(tf$selected.index)) stop("No trend-filtering candidate passed every fold and the full fit.")
    list(basic=basic, spline=spline, tf=tf,
         spline_cv=data.frame(df=spline_df, log.loss=cv_loss,
                              eligible=is.finite(cv_loss)),
         spline_fold_status=spline_status)
}
predict_comparison <- function(object, x, covariates=NULL) {
    ans <- vapply(object$basic, function(f) predict_reference(f, x, covariates), numeric(length(x)))
    ans <- cbind(ans, predict_reference(object$spline, x, covariates),
                 as.numeric(stats::predict(object$tf, x, covariates=covariates, type="link")))
    colnames(ans) <- method_names
    stopifnot(all(is.finite(ans)))
    ans
}
score_comparison <- function(object, x, y, truth=NULL, covariates=NULL) {
    eta <- predict_comparison(object, x, covariates)
    out <- t(vapply(seq_len(ncol(eta)), function(j)
        probability_scores(y, eta[, j], truth), numeric(3)))
    data.frame(Model=colnames(eta), out, row.names=NULL, check.names=FALSE)
}

bin_summary <- function(x, y, bins=8L) {
    breaks <- unique(as.numeric(stats::quantile(x, seq(0,1,length.out=bins+1))))
    group <- if (length(breaks)<2) rep(1L, length(x)) else
        cut(x, breaks=breaks, include.lowest=TRUE, labels=FALSE)
    out <- do.call(rbind, lapply(split(seq_along(x), group), function(i) {
        n <- length(i); p <- mean(y[i]); z <- stats::qnorm(.975)
        center <- (p+z^2/(2*n))/(1+z^2/n)
        half <- z*sqrt(p*(1-p)/n+z^2/(4*n^2))/(1+z^2/n)
        data.frame(x=mean(x[i]), observed=p, n=n, lower=center-half, upper=center+half)
    }))
    rownames(out) <- NULL; out
}
