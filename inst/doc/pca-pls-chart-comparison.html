PCA describes directions with large variation in the predictors. PLS also uses the training response, so it can retain a direction with little geometric variation but a strong relationship with the response. This advantage is conditional: a noisy binary response can give unstable supervised directions, and neither method guarantees that a small chart captures a nonlinear response.

This vignette compares the methods using known binary-response probabilities. It separates two questions: does unfolding remove a geometric bend, and does a response-informed chart improve prediction? All computations below use the public fit.local.likelihood() and unfold.simplex.chart() interfaces. The local simplex charts guide gives the mathematical and implementation details.

First inspect the geometry

We place points on two adjacent faces of the nonnegative max-normalized simplex. A latent coordinate t runs from -0.2 to 0.2. It maps to (1, 1+t) on one face and (1-t, 1) on the other. Additional coordinates vary below one. The simplex is the surface with at least one coordinate equal to one; distances are shortest Euclidean-length paths constrained to that surface.

t.line <- c(seq(-.2, -.005, length.out=30), seq(.005, .2, length.out=30))

Retaining more variance is a geometric result, not evidence of better outcome prediction. The examples below test prediction separately. Both folded and unfolded charts use the same intrinsic neighbors and weights. Unfolding can be rejected near corners, tied maxima or more than two faces; such cases are counted rather than silently forced into a chart.

Define examples before comparing methods

Each observation has six coordinates. The seam coordinate t and a broad coordinate u3 vary substantially. A narrow coordinate u4 has a much smaller range; the remaining two coordinates are nuisance features. The table gives the true log odds. The true probability is plogis(eta) and the observed response is a Bernoulli draw with that probability.

Example True log odds, eta Question
Seam -1 + 2 t/0.2 Does a chart retain variation across the bend?
High variance -1 + 2 (u3-0.3)/0.2 Can PCA capture a signal aligned with broad variation?
Low variance -1 + 2 (u4-0.12)/0.02 Does supervised PLS recover a narrow signal direction?
Constant -1 Does adaptation to binary noise hurt prediction?
Nonlinear -1 + 2.5 ((t/0.2)^2 - 1/3) How do local linear charts handle a symmetric nonlinear signal?

The narrow coordinate varies from 0.10 to 0.14. Its contribution to the log odds is deliberately as large as that of the broad coordinate in the high-variance example. This is a stress test for variance-based dimension reduction, not a claim about the frequency of such signals in real datasets. Predictor features are not standardized before constructing directions: doing so would change the geometry and would remove part of the contrast we intend to study. Component scores are scaled inside the local logistic fit.

scenarios <- c("Seam", "High variance", "Low variance", "Constant", "Nonlinear")
make.example <- function(seed, scenario, n=360L) {
    set.seed(seed)
    t <- runif(n, -.2, .2)
    X <- cbind(ifelse(t < 0, 1, 1-t), ifelse(t < 0, 1+t, 1),
               runif(n, .1, .5), runif(n, .10, .14),
               runif(n, .02, .06), runif(n, .02, .06))
    eta <- switch(scenario,
        "Seam"=-1+2*t/.2,
        "High variance"=-1+2*(X[,3]-.3)/.2,
        "Low variance"=-1+2*(X[,4]-.12)/.02,
        "Constant"=rep(-1,n),
        "Nonlinear"=-1+2.5*((t/.2)^2-1/3))
    probability <- plogis(eta)
    list(X=X, y=rbinom(n,1,probability), probability=probability, t=t)
}

Fit on training observations; choose dimension on tuning observations

Each of five independent repetitions per example has 180 training, 60 tuning and 120 test observations. The observations are independent in this simulation. For repeated specimens or matched sets, splitting must respect those groups instead.

We compare ambient PCA, unfolded PCA and unfolded PLS. All use 60 training neighbors, Gaussian weights, a fixed slope ridge penalty of 1, and half-success/ half-failure intercept pseudo-counts. Support size and ridge penalty are held fixed to make the chart comparison interpretable; they are not claimed optimal.

We report both a fixed one-dimensional chart and a chart dimension chosen from 1, 2 and 3 by the lowest tuning Brier loss. Ties choose the first (smaller) dimension. Tuning predictions use training observations only. Final test predictions use the same training fits; the tuning observations are not added to the training set. Test outcomes and true probabilities never select the model.

methods <- c("Ambient PCA", "Unfolded PCA", "Unfolded PLS")
fit.chart <- function(X, y, query, method, dimension, degree=1L) {
    fit.local.likelihood(X, y, X.eval=query, likelihood.family="bernoulli",
        chart.geometry="linf.simplex", unfold.faces=method != "Ambient PCA",
        coordinate.method=if (method == "Unfolded PLS") "local.pls" else "local.pca",
        support.size=60L, chart.dim=dimension, degree=degree,
        kernel="gaussian", lambda.ridge=1, intercept.mass=.5,
        max.iter=70L, tol=1e-7, fallback="degree0")
}
train <- 1:180
tune <- 181:240
test <- 241:360

The following loop defines the comparison. A local constant uses the same neighbors and weights but no chart directions. A global constant uses the smoothed overall training proportion. Both are useful controls, particularly when the true probability is constant.

The displayed results retain all 25 repetitions. Routine rendering reads their stored results; the reproduction instructions below rerun this loop with the same seeds, sample sizes and fitting settings. Geometry demonstrations and conditional probability slices are computed during every render.

rows <- list()
illustrations <- list()
append.result <- function(scenario, repetition, method, mode, dimension,
                          prediction, truth, response, fallbacks, tuning.fallbacks=NA_integer_) {
    stopifnot(all(is.finite(prediction)), all(prediction > 0 & prediction < 1))
    data.frame(scenario=scenario, repetition=repetition, method=method,
        mode=mode, dimension=dimension,
        probability.mse=mean((prediction-truth)^2),
        brier=mean((prediction-response)^2),
        log.loss=-mean(response*log(prediction)+(1-response)*log1p(-prediction)),
        fallbacks=fallbacks, tuning.fallbacks=tuning.fallbacks)
}
for (s in seq_along(scenarios)) for (repetition in 1:5) {
    scenario <- scenarios[s]
    dat <- make.example(271000+100*s+repetition, scenario)
    example.predictions <- list()
    for (method in methods) {
        fits <- lapply(1:3, function(d) fit.chart(dat$X[train,], dat$y[train],
            dat$X[c(tune,test),], method, d))
        tuning.loss <- vapply(fits, function(f)
            mean((f$fitted.values[1:60]-dat$y[tune])^2), numeric(1))
        best <- which.min(tuning.loss)
        for (mode in c("One dimension", "Tuned dimension")) {
            d <- if (mode == "One dimension") 1L else best
            chosen <- fits[[d]]
            prediction <- chosen$fitted.values[61:180]
            rows[[length(rows)+1L]] <- append.result(scenario, repetition, method,
                mode, d, prediction, dat$probability[test], dat$y[test],
                sum(chosen$diagnostics$per.eval$fallback[61:180]),
                sum(chosen$diagnostics$per.eval$fallback[1:60]))
            if (repetition == 1L) example.predictions[[paste(method,mode)]] <- prediction
        }
    }
    local <- fit.chart(dat$X[train,], dat$y[train], dat$X[test,],
                       "Ambient PCA", dimension=1L, degree=0L)
    constants <- list("Local constant"=local$fitted.values,
        "Global constant"=rep((sum(dat$y[train])+.5)/(length(train)+1), length(test)))
    for (method in names(constants)) {
        rows[[length(rows)+1L]] <- append.result(scenario, repetition, method,
            "Constant", 0L, constants[[method]], dat$probability[test], dat$y[test], 0L)
        if (repetition == 1L) example.predictions[[method]] <- constants[[method]]
    }
    if (repetition == 1L) illustrations[[scenario]] <- list(data=dat,
        predictions=example.predictions)
}
results <- do.call(rbind, rows)
stopifnot(nrow(results) == 200L)

Measure estimation and prediction separately

Probability mean squared error (MSE) compares the predicted probability with the known true probability. It directly measures estimation accuracy here. Brier loss compares the prediction with the binary response; it includes irreducible Bernoulli variation. Lower values are better for both. Test log loss is also retained in results for inspection. Neither a low MSE nor a converged optimizer alone establishes uncertainty calibration.

The table shows the mean across five repetitions. The figures show every repetition as well as the mean, so an apparently favorable average cannot hide a reversal. Five repetitions make a compact teaching example, not a powered simulation study or a universal ranking of methods.

A fallback is a failed chart certificate or failed optimizer replaced by the smoothed local proportion. Such predictions remain in the performance scores. They are not discarded to improve apparent performance. The table counts only reported rank-one or selected fits; its two modes reuse some fits and must not be added together as independent failures. results also retains each selected dimension and each test log loss.

Reading the comparison

The low-variance example shows why response-informed directions are not enough by themselves. With one dimension, unfolded PCA and PLS have mean probability MSEs of 0.0472 and 0.0473, respectively. After selecting dimension on the tuning observations, these become 0.0442 and 0.0162. Weighted PLS uses covariance and is still affected by predictor scale, binary noise and the number of retained directions. Its narrow-signal advantage here appears after dimension selection, not from its first direction alone.

The constant example favors the global constant in known-probability MSE. In the high-variance example, dimension-tuned PCA has a smaller mean probability MSE than dimension-tuned PLS. Dimension tuning itself sometimes worsens test performance relative to the one-dimensional fit: 60 tuning observations give a noisy selection criterion. These comparisons explain why the vignette shows baselines, fixed and selected dimensions, and every repetition.

The seam example distinguishes correcting a geometric fold from learning a response direction. The high-variance example is favorable to PCA’s criterion; the low-variance example deliberately puts important response information in a direction PCA may discard. Increasing the chart dimension gives PCA a chance to recover that information, with additional estimation variability. PLS can help at low dimension, but its supervised directions must be learned exclusively from training data.

The constant example is an essential control: there is no informative direction to recover. The nonlinear example asks whether local neighborhoods make a nonlinear function adequately linear; the local PLS covariance can be weak near symmetry points even when the response depends strongly on position. No method is assumed to win these comparisons. Differences among individual repetitions, not just averages, matter.

For a scientific analysis, expand the simulation to realistic sample sizes, class balance, dependence, missingness and geometry. Tune support size and regularization inside training data, assess probability calibration on an outer hold-out sample, and examine performance near corners or low-support regions. For case-control sampling, recovering conditional probability in the selected sample does not identify population prevalence without sampling information.
